# 鱼宜原材手机看板

GitHub Pages 移动网页。水稳页展示功能层、底基层、基层的原材累计进场、合并进场批次、理论消耗和差值，支持全部站点及 1#/2# 筛选。沥青、混凝土为待接入页。

浏览器不再每 60 秒自动刷新，仅在打开页面或用户刷新时更新；读取脚本仅能读取水稳原材统计 A1:J20，校验行名后转换为看板约定的 16 行结构，密钥为云端环境变量，不进入网页或仓库。接口最多复用 30 秒读取结果。离线缓存明确标注原读取时间。

源数据为金山文档《自用_施工台账》的统计表当前值。打开或刷新网页以及在顶部下拉并松手时，匿名提交固定更新任务，由 NAS 已登录的浏览器执行跨表引用更新，确认完成后重新读取统计。多人请求共用任务，一分钟最多执行一次；页面提示“下拉更新台账”，访问者无需输入 NAS 密码。引用成功时间由服务端持久记录，与数据读取时间分开显示；失败不覆盖上次成功时间。执行密钥仅保存在云端和 NAS，管理入口仍需认证。

差值为进场减理论，仅为统计差额，不等同库存或损耗。

手机兼容：不依赖 AbortSignal.timeout。网页同时请求实时接口和同域 data.json；备用快照由 GitHub Actions 每 5 分钟计划读取并发布，调度可能延迟。页面保留真实 readAt，超过 15 分钟明确标记过期；同步失败时停止部署，继续提供上次有效数据。密钥仅在 Actions Secrets 和云服务环境变量中保存。
